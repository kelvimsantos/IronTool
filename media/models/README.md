# Modelos 3D de demonstração

`demo-triangle.gltf` é um modelo mínimo de demonstração criado para o IronTool. Ele usa geometria incorporada no próprio arquivo e não depende de arquivos binários adicionais.

Para adicionar outros modelos, coloque arquivos `.glb` ou `.gltf` nesta pasta e envie um commit. O build copia `media/` para a aplicação; o Render fará o deploy automático. Para hologramas, use `media/holo/`. Verifique a licença do modelo antes de incluí-lo no repositório.
